# Tefsir Usulü · Giray Akademi

İhtisas kursu Tefsir Usulü dersi için çalışma programı: 10 ünite konu anlatımı, karşılaştırma tabloları, ünite sonu hızlı tekrar kutuları, kavram kartları, eser–müellif eşleştirme, açıklamalı testler ve cevaplı geçmiş sınav soruları.

Adres: https://alpkiraym.github.io/tefsir_usulu/

## Düzenleme

İçerik `kaynak/` klasöründedir; `index.html` buradan üretilir, elle düzeltilmez.

- `01.txt … 10.txt`: üniteler (biçim `kaynak/derle.py` başında anlatılıyor)
- `sorular.txt`: el ile hazırlanmış test soruları
- `sinav.txt`: geçmiş sınav soruları ve cevapları
- `sablon.html`: görünüm ve kod
- `bildir.html`, `altcubuk.html`: Giray Akademi ortak parçaları (değiştirilmez)

Derleme: `python3 kaynak/derle.py`

Kayıt ön eki: `tu_`
